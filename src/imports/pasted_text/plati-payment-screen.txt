VISUAL STYLE RULES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- No hard shadows — only box-shadow: 0 2px 12px rgba(124,77,255,0.08)
- All cards use 1px border #D1C4E9 + subtle violet shadow
- Spacing unit: 8px base grid (8/16/24/32px)
- Icons: Tabler Icons style (stroke, not filled)
- Hover states: bg shifts to #EDE7F6, border to #7C4DFF
- No gradients except optional subtle on sidebar
- Monto hero ($206.000) must be the LARGEST text on screen
- "Pagar ahora" button must have highest visual contrast
